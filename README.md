# Nuxeia for macOS and Windows

Download the latest version from [Releases](https://github.com/Room-245/nuxeia-desktop/releases/latest):

- Mac with Apple silicon: `Nuxeia-mac-arm64.dmg`
- Mac with Intel: `Nuxeia-mac-x64.dmg`
- Windows: `Nuxeia-Setup.exe`

An installed app checks this repository's latest release for updates. The app's code is private; this repository
holds only the installers and the update feed.
